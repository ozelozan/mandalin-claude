# Kaynak dosyalar

RKR207 Eğitsel Oyunlar ödevinin üretim betikleri ve girdileri.

- `build.js` — PowerPoint sunumunu üretir (pptxgenjs). Bu klasörde `ana_oyun.mp4` yanında olmalı (`../ana_oyun.mp4` kopyalanarak).
- `fix_video.py` — sunumdaki videoya PowerPoint oynatma kaydını (`<p:timing>`) ekler. `build.js` sonrası çalıştırılır.
- `build_docx.js` — Word belgesini üretir (docx).
- `logo.png` — örnek kapaktan kırpılan üniversite logosu (düşük çözünürlük).
- `poster.png` — videonun kapak karesi.
- `ornek-kapak.jpg` — kullanıcının gönderdiği örnek kapak.
